# Task 01: Install markdown dependencies

## Location

- `packages/dashboard/package.json` (modify)
- `packages/dashboard/package-lock.json` (generated by install)

## Dependencies

- None (first task in FR-11)

## What to build

Add npm packages for safe markdown rendering in the dashboard.

## Design spec

### Packages

```bash
cd packages/dashboard
npm install react-markdown remark-gfm rehype-sanitize
```

| Package | Purpose |
|---------|---------|
| `react-markdown` | Render markdown AST to React elements |
| `remark-gfm` | GitHub-flavored markdown: tables, strikethrough, task lists |
| `rehype-sanitize` | Strip dangerous HTML; no raw HTML passthrough |

### Version guidance

- `react-markdown` ^9.x (compatible with React 18)
- Pin minor versions in package.json per repo convention

### Verify

After install:

```bash
npm run build
```

Ensure no peer dependency warnings that break Vite build.

### Do not install

- `rehype-raw` — explicitly forbidden (XSS risk)
- Heavy syntax highlighters (optional later)

## Done when

- [ ] All three packages listed in `dependencies` (not devDependencies).
- [ ] `npm run build` succeeds in `packages/dashboard`.
- [ ] Docker dashboard image rebuild includes new deps (`docker compose build dashboard`).
